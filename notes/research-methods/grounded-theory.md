# 扎根理论（Grounded Theory）笔记

## 1. 什么是扎根理论

扎根理论是一种**从原始数据中归纳概念、类别和理论**的研究方法。

它不是先设定完整分类，再拿数据验证，而是：

```text
收集数据
→ 逐条分析
→ 添加初始标签
→ 合并相似标签
→ 形成类别
→ 建立分类体系或解释框架
```

一句话理解：

> 让分类和理论从数据中“长出来”。

---

## 2. 什么是编码

给数据中的现象贴上概念标签。

例如，一条 Agent 轨迹是：

```text
Agent 没有查询当前订单，直接修改订单地址。
```

可以编码为：

```text
跳过状态读取
缺少前置验证
无证据写操作
```

分析更多轨迹后，可以将相似编码合并为：

```text
缺少写前证据
```

---

## 3. 常见步骤

### 开放编码

逐条阅读数据，提取初始标签。

### 主轴编码

将相似标签合并为更高层类别，并分析类别之间的关系。

### 选择性编码

找到核心问题，将主要类别组织成整体框架。

例如：

```text
工具调用证据不足
├── 未执行必要读取
├── 使用过期信息
├── 忽略已有证据
└── 缺少写后验证
```

---

## 4. 持续比较

每分析一条新轨迹，都要和已有类别比较：

* 是否属于已有类别；
* 是否需要增加新类别；
* 是否需要合并或拆分类别；
* 类别边界是否清楚。

这称为持续比较法。

---

## 5. 理论饱和

当继续分析新数据时，已经很少出现新的重要类别，就可以认为分类体系逐渐达到理论饱和。

这不代表以后绝对不会出现新类别，只表示：

> 在当前数据范围内，分类体系已经比较稳定。

---

## 6. 在 AI Agent 研究中的用途

扎根理论适合用于：

* 分析 Agent 执行轨迹；
* 归纳工具调用失败模式；
* 构建失败 taxonomy；
* 制定人工标注规则；
* 从失败现象中提出新的研究问题。

例如：

```text
分析大量 Agent 轨迹
→ 发现经常出现无读取直接写入
→ 归纳为 Read-before-Write 违规
→ 设计 Governor 进行阻断
→ 用实验验证治理效果
```
